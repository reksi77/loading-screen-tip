A single sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer. The program writes exactly one line to `/output/entry.txt`: a tip about an agent that guessed what you meant instead of asking — and the one thing you should do about it, check the diff.

## Run it

```sh
node main.ts
```

This writes the tip to `/output/entry.txt` (creating `/output` if needed). The output is deterministic: every run writes the same bytes.
